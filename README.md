# MEMORY//BREACH

MEMORY//BREACH is a 2D cyberpunk action game built in Godot. You play as PATCH, exploring a locked-down memory archive while a corporation tries to erase the evidence hidden inside it. The memory shards you recover gradually reveal what happened to Elena and why the archive was sealed.

The game has ten sectors, starting with simple patrols and puzzles before introducing tougher enemies, lasers, and more complicated routes. Alongside shooting and shield combat, you use an in-game Python terminal to solve number and logic puzzles and breach security systems. The final sector brings you face to face with KAVYA, who guards the last memory shard and calls in reinforcements as you fight.
